Milestone Syllabus

Detailed Module Breakdown

Each module combines theoretical foundations with practical code deliverables.

Module 1 Core Milestone

Semantic HTML5, Architecture & Accessibility

  • Accessible ARIA attributes, keyboard tab order, and screen-reader testing
  • Clean URL conventions, meta tags, and Open Graph configurations
Deliverable: Deliver an accessible, valid static markup skeleton conforming to WCAG 2.1 AA.
Module 2 Core Milestone

Modern CSS Architecture & Apple-Inspired Design Tokens

  • CSS custom properties (tokens), color palette design, and typography hierarchy
  • Responsive layout engineering with CSS Grid and Flexbox (no bloated frameworks)
  • Micro-interactions, smooth hover transitions, and reduced-motion media queries
Deliverable: Construct a complete, framework-free design system with responsive breakpoints.
Module 3 Core Milestone

Client-Side JavaScript & Async API Integration

  • ES6+ syntax, DOM manipulation, and event delegation patterns
  • Form validation with native Constraint Validation API and async Fetch requests
  • Secure state management without insecure localStorage token storage
Deliverable: Implement an interactive, asynchronously validated form with real-time feedback.
Module 4 Core Milestone

Performance Engineering & Core Web Vitals Optimization

  • Largest Contentful Paint (LCP) diagnostics and critical rendering paths
  • Cumulative Layout Shift (CLS) prevention through explicit aspect ratios
  • Automated validation pipelines and lighthouse performance auditing
Deliverable: Audit and optimize a web application to achieve 95+ Lighthouse performance scores.

Eligibility & Prerequisites

Students or graduates enrolled in BCA, B.Tech, Computer Science, or related degrees with basic understanding of web basics.

Technical Equipment:

Personal laptop/desktop, code editor (VS Code recommended), modern browser (Chrome/Edge/Firefox), and 10-12 hours per week commitment.
