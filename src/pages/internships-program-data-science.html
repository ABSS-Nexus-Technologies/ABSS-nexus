Milestone Syllabus

Detailed Module Breakdown

Each module combines theoretical foundations with practical project deliverables.

Module 1 Beginner-Friendly

Milestone 1: Data Acquisition & Exploratory Data Analysis (EDA)

Ingest multi-source tabular datasets, handle missing values, and calculate statistical distribution metrics.

  • Load raw CSV/JSON datasets into Pandas DataFrames and audit data types and missing values
  • Generate descriptive statistics (mean, median, IQR, variance, skewness)
  • Produce distribution histograms, box plots, and scatter matrices using Seaborn & Matplotlib
  • Document 5 key analytical insights discovered from initial exploration
Expected Deliverable: Estimated time: 6–8 hrs. Verification via GitHub repo or live project proof.
Module 2 Intermediate

Milestone 2: Feature Engineering & Preprocessing Pipeline

Build an automated data cleaning and feature engineering transformation pipeline.

  • Implement one-hot and target encoding for high-cardinality categorical variables
  • Apply standard/min-max feature scaling and power transformations
  • Detect and treat multi-variate outliers using IQR and Z-score methods
  • Assemble transformations into a reproducible Scikit-Learn Pipeline object
Expected Deliverable: Estimated time: 8–10 hrs. Verification via GitHub repo or live project proof.
Module 3 Intermediate

Milestone 3: Predictive Modeling & Baseline Evaluation

Train supervised classification and regression algorithms, establishing rigorous benchmark baselines.

  • Split data using stratified k-fold cross-validation to prevent data leakage
  • Train Logistic Regression, Random Forest, and Gradient Boosting baseline models
  • Calculate accuracy, precision, recall, F1-score, and ROC-AUC metrics
  • Plot confusion matrix and precision-recall trade-off curves
Expected Deliverable: Estimated time: 10–12 hrs. Verification via GitHub repo or live project proof.
Module 4 Advanced

Milestone 4: Hyperparameter Optimization & Model Explainability

Fine-tune model hyperparameters using Optuna/GridSearch and explain feature importance with SHAP.

  • Run Bayesian hyperparameter search using Optuna across learning rate and tree depth
  • Compute SHAP (SHapley Additive exPlanations) summary plots and feature importance
  • Perform residual analysis to diagnose model bias and heteroscedasticity
  • Serialize best performing model using Joblib with schema versioning
Expected Deliverable: Estimated time: 10–12 hrs. Verification via GitHub repo or live project proof.
Module 5 Capstone

Milestone 5: Interactive Streamlit Dashboard & Executive Insights Deck

Deploy an interactive web dashboard for non-technical stakeholders with live inference.

  • Develop interactive Streamlit/Gradio web application with dynamic filter sliders
  • Allow users to upload CSVs or enter features to receive real-time predictions
  • Deploy application to Streamlit Community Cloud or Hugging Face Spaces
  • Draft executive summary report with business recommendations
Expected Deliverable: Estimated time: 12–14 hrs. Verification via GitHub repo or live project proof.

Eligibility & Prerequisites

Students with basic Python programming knowledge and an interest in data-driven discovery and statistical modeling.

Technical Equipment & Commitment:

Python 3.10+ environment, Jupyter Notebooks or Google Colab, and 10-12 hours weekly commitment.
