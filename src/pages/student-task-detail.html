Assignment Objective

Implement cryptographic session validation and token verification on Cloudflare Workers edge nodes. Ensure all protected routes redirect unauthenticated traffic and prevent timing attacks using constant-time comparison.

Acceptance Criteria

  • Read abss_student_session HttpOnly cookie from request headers.
  • Hash raw cookie token with SHA-256 and query active session records.
  • Return HTTP 401 Unauthorized for expired or missing tokens.
  • Pass 100% of automated Jest integration tests without regression.
